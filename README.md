# Personal Information Form Application (Java Swing)

This project is a simple **personal information registration and display** application developed using Java Swing.  
The program collects a user's first name, last name, age, phone number, and email, then stores and displays them in a table.

---

## 🚀 Features

- Input fields for:
  - First Name
  - Last Name
  - Age
  - Phone Number
  - Email
- Stores all entered data in an `ArrayList`
- Displays all saved records in a `JTable`
- Simple and clean graphical interface using Java Swing

---

## 🖥 User Interface

- Input fields are located on the left
- A `JTable` is placed on the right to show added users
- **Save** button → Temporarily adds entered data into the list  
- **Show** button → Loads all saved users into the table

---

## 🛠 Technologies Used

- **Java 8+**
- **Java Swing**
- **DefaultTableModel**
- **ArrayList**
